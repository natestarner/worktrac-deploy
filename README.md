# Workout Tracker — Deploy Repo

Holds per-environment config, the current image tag, the built frontend artifact, and the
CD workflows that deploy to Azure. See the setup guide (Section 10) and `worktrac-source`'s
CLAUDE.md for context. Until custom domains (Section 13) are bound, use the Azure-assigned
Container Apps / Static Web Apps hostnames in place of the starnerconsulting.co subdomains
referenced in these config files.
